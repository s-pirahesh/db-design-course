## 📖 درباره پروژه

این پروژه یک وبسایت آموزشی جامع و تعاملی برای درس **طراحی پایگاه داده** است که به صورت کامل به زبان فارسی نوشته شده است. محتوای این وبسایت بر اساس کتاب **دکتر روحانی رنکوهی** تهیه شده و شامل 7 فصل، 33 بخش آموزشی، بیش از 200 تمرین و مثال، و بیش از 150 نمودار و جدول است.

## ✨ ویژگی‌ها

- ✅ **33 صفحه آموزشی** با محتوای کامل و جامع
- 🎨 **طراحی مدرن و ریسپانسیو** - سازگار با موبایل، تبلت و دسکتاپ
- 🌙 **تم روشن/تاریک** با امکان تغییر با یک کلیک
- 🔍 **جستجوی پیشرفته** در تمام محتوا
- 📊 **نمودارهای تعاملی** با Mermaid.js
- 💻 **هایلایت کد** با Prism.js
- 📱 **منوی کناری هوشمند** با پیگیری پیشرفت
- ⚡ **بدون نیاز به سرور** - فقط مرورگر کافی است
- 🔄 **عملکرد آفلاین** - تمام فایل‌ها محلی هستند

## 📚 محتوای آموزشی

### فصل 1: مفاهیم بنیادی و فلسفه پایگاه داده
- داده، اطلاع و دانش
- سلسله مراتب داده
- داده مانا و عملیاتی
- نسل‌های DBMS
- مشکلات سیستم فایلینگ
- معماری متمرکز و کلاینت-سرور
- معماری توزیع‌شده و شفافیت

### فصل 2: مدل‌سازی مفهومی با ER/EER
- موجودیت‌ها (قوی/ضعیف)
- صفات و دامنه
- ارتباط و درجه
- چندی (Cardinality)
- مشارکت (کلی/جزئی)
- وراثت و Is-A
- محدودیت‌های تخصیص
- U-Type و Aggregation

### فصل 3: معماری سیستم‌های پایگاه داده
- ساختار سلسله مراتبی (HDS)
- معماری ANSI-SPARC
- دیدها (Views)
- استقلال داده‌ای

### فصل 4: مدل رابطه‌ای
- تعریف ریاضی رابطه
- تئوری کلیدها
- قواعد نگاشت از ER به رابطه‌ای (3 بخش)

### فصل 5: جامعیت رابطه‌ای
- جامعیت عام (Domain, Entity, Referential)
- قیود خاص و قواعد کسب‌وکار

### فصل 6: زبان‌های پرس‌وجو
- جبر رابطه‌ای
- عملگرهای پیشرفته
- حساب رابطه‌ای

### فصل 7: نرمال‌سازی
- آنومالی و وابستگی تابعی
- فرم‌های نرمال پایه (1NF, 2NF, 3NF)
- فرم‌های نرمال پیشرفته (BCNF, 4NF, 5NF)

## 🚀 نصب و اجرا

### پیش‌نیازها
- مرورگر مدرن (Chrome, Firefox, Safari, Edge)
- (اختیاری) Python 3 برای اجرای سرور محلی

### روش 1: باز کردن مستقیم
```bash
# دانلود پروژه
git clone https://github.com/YOUR_USERNAME/db-design-course.git
cd db-design-course

# باز کردن index.html در مرورگر
# Windows:
start index.html

# macOS:
open index.html

# Linux:
xdg-open index.html
```

### روش 2: استفاده از سرور محلی
```bash
# با Python
python3 -m http.server 8000

# یا با Node.js
npx serve

# سپس باز کنید:
http://localhost:8000
```

## 🎯 ویژگی‌های پیشرفته

### تم روشن/تاریک
- تغییر خودکار با کلیک روی دکمه 🌙/☀️
- ذخیره‌سازی انتخاب کاربر در localStorage
- سازگار با تمام اجزای صفحه

### جستجوی هوشمند
- جستجو در عنوان‌ها و کلمات کلیدی
- نمایش نتایج با هایلایت
- لینک مستقیم به صفحات

### منوی کناری
- نمایش ساختار کامل دوره
- باز/بسته شدن فصل‌ها
- نشان‌گذاری صفحه فعلی
- نوار پیشرفت

### کپی کد
- دکمه کپی برای تمام بلاک‌های کد
- در دسکتاپ: نمایش با hover
- در موبایل: همیشه قابل مشاهده

## 📱 ریسپانسیو

- **دسکتاپ** (>768px): منوی ثابت در کنار
- **تبلت** (768px): منوی کشویی
- **موبایل** (<480px): بهینه‌سازی کامل
