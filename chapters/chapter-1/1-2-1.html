📖 نسل اول: دوران ابتدایی (بدون File System)

دوره زمانی: دهه 1950

تعریف: نسل اول: فایل سیستم (FS) وجود نداشت و خود برنامه‌نویس مجبور بود توابع مربوط را انجام دهد و مستقیماً با رسانه ذخیره‌سازی کار می‌نمود. زمان‌بر و هزینه‌بر بود. چون سیستم عامل ندارد.

چرا "بدون File System"؟

در این دوران:

  • سیستم عامل وجود نداشت ❌
  • هیچ ابزاری برای مدیریت فایل نبود ❌
  • برنامه‌نویس باید همه چیز رو خودش می‌نوشت 😰

چالش‌های این دوران

1. کنترل مستقیم رسانه ذخیره‌سازی

برنامه‌نویس باید:

  • آدرس فیزیکی روی دیسک رو محاسبه کنه
  • سکتور و Track رو مشخص کنه
  • خودش Read/Write انجام بده
مثال: ذخیره رکورد دانشجو
↓
برنامه‌نویس باید بنویسه:
1. محاسبه آدرس: Track 15, Sector 8
2. نوشتن مستقیم: WRITE(Track=15, Sector=8, Data=StudentRecord)
3. کنترل خطا: IF Error THEN Retry

2. زمان‌بر و هزینه‌بر

کارزمان (تخمینی)
نوشتن یک برنامه ساده6 ماه
رفع اشکال3 ماه
تغییر ساختار داده2 ماه
جمع11 ماه!
هر برنامه‌نویس باید همه چیز از صفر می‌نوشت! 😱

مثال عملی: سیستم حقوق دانشگاه

برای ذخیره حقوق یک استاد، برنامه‌نویس باید:

1. محاسبه فضای مورد نیاز (دستی)
   نام: 20 بایت
   شماره پرسنلی: 4 بایت  
   حقوق: 4 بایت
   جمع: 28 بایت

2. پیدا کردن جای خالی روی دیسک
   بررسی Track 0 → پر است
   بررسی Track 1 → پر است
   ...
   بررسی Track 45 → خالی است ✓

3. نوشتن کد برای ذخیره:
   WRITE(Track=45, Sector=3, Offset=0, Length=28, Data=TeacherData)

4. نوشتن کد برای خواندن:
   READ(Track=45, Sector=3, Offset=0, Length=28) → Data

5. اگر خطا رخ بده، خودت باید مدیریت کنی!

🗂️ نسل دوم: ظهور File System

دوره زمانی: دهه 1960

تعریف: نسل دوم: فایل سیستم وجود داشت. برنامه‌های کاربردی با واسطه فایل‌های سیستم، با رسانه‌های ذخیره‌سازی کار می‌نمودند. برنامه‌نویس درگیر کار با فایل‌ها بود.

مزایای نسل دوم

1. انتزاع (Abstraction)

برنامه‌نویس دیگه نیاز نداشت با Track و Sector کار کنه! فقط کافی بود بگه: 

نسل اول (بد):
WRITE(Track=45, Sector=3, Data)

نسل دوم (خوب):
File f = OPEN("teachers.dat")
WRITE(f, Data)
CLOSE(f)

2. استفاده مجدد

حالا File System یک‌بار نوشته می‌شد و همه برنامه‌ها ازش استفاده می‌کردن!

قبل (نسل اول)بعد (نسل دوم)
هر برنامه‌نویس کد خودش رو می‌نوشتهمه از File System استفاده می‌کنن
1000 برنامه = 1000 کد تکراری1000 برنامه = 1 File System
#### چالش‌های نسل دوم

اما هنوز مشکلات زیادی داشت:

1. برنامه‌نویس هنوز درگیر فایل‌ها بود 

برای پیدا کردن حقوق یک استاد:

1. OPEN("teachers.dat")
2. خودت باید loop بزنی روی همه رکوردها
3. مقایسه کنی که کدوم رکورد مال استاد مورد نظرته
4. اگر پیدا کردی، بخونی
5. CLOSE("teachers.dat")

2. هیچ امکانات پیشرفته‌ای نداشت

  • جستجوی سریع؟ خودت بنویس ❌
  • مرتب‌سازی؟ خودت بنویس ❌
  • شاخص (Index)؟ خودت بنویس ❌

مثال مقایسه: جستجوی استاد

نسل اول (وحشتناک): 

// باید خودت Track و Sector رو حساب کنی!
FOR Track = 0 TO 100
  FOR Sector = 0 TO 16
    Data = READ(Track, Sector)
    IF Data.TeacherID == 123 THEN Found!
  END
END

نسل دوم (بهتر ولی هنوز سخت): 

File f = OPEN("teachers.dat")
WHILE NOT EOF(f)
  Record = READ(f)
  IF Record.TeacherID == 123 THEN Found!
END
CLOSE(f)

هنوز برنامه‌نویس باید خودش loop بزنه و جستجو کنه! 😓

🔧 نسل سوم: ظهور DMS (Data Management System)

دوره زمانی: اواخر دهه 1960 و اوایل دهه 1970

تعریف: DMS (Data Management System): علاوه بر امکانات FS (فایل سیستم)، امکاناتی مانند زدن شاخص یا مرتب‌سازی را نیز در اختیار برنامه‌نویس قرار می‌دهد.

امکانات جدید DMS

1. شاخص‌گذاری (Indexing) 

قبل از DMS:
برای پیدا کردن Teacher با ID=123، باید کل فایل رو بخونی!
→ 10,000 رکورد → خیلی کند 🐌

با DMS:
یک Index (شاخص) روی TeacherID می‌سازیم
→ جستجوی سریع! ⚡

مثال: 

Index روی TeacherID:
ID=100 → Record در Position 0
ID=123 → Record در Position 450  ← پیداش کردیم!
ID=200 → Record در Position 1200
...

حالا دیگه نیازی نیست کل فایل رو بخونیم!

2. مرتب‌سازی (Sorting) 

قبل از DMS:
برای مرتب کردن اساتید بر اساس نام:
→ خودت باید الگوریتم Sort بنویسی (Bubble Sort, Quick Sort, ...)
→ 500 خط کد! 😰

با DMS:
CALL SORT("teachers.dat", BY="Name")
→ 1 خط کد! 😊

مزایای DMS

      کمتر اشکال

چالش‌های DMS

اما هنوز مشکلات زیادی داشت:

1. فقط امکانات محدود

DMS فقط Index و Sort داشت. چیزهای دیگه نداشت:

  • امنیت؟ ❌
  • کنترل همزمانی (Concurrency)؟ ❌
  • بازیابی از خرابی (Recovery)؟ ❌
  • ارتباط بین داده‌ها؟ ❌

2. برنامه‌نویس هنوز درگیر جزئیات بود 

برای پیدا کردن "اساتید دانشکده کامپیوتر":

1. OPEN("teachers.dat")
2. CREATE_INDEX("teachers.dat", "Department")
3. SEARCH(Index, "Computer")
4. READ_RECORDS(Results)
5. CLOSE("teachers.dat")

هنوز زیادی پیچیده بود! 🤔

💾 نسل چهارم: انقلاب DBMS (Database Management System)

دوره زمانی: دهه 1970 و 1980

تعریف: DBMS (Database Management System): سیستمی برای مدیریت پایگاه داده که امکانات کاملی برای ذخیره، بازیابی، امنیت، و مدیریت داده‌ها فراهم می‌کند.

امکانات کامل DBMS

1. زبان Query (SQL) 

قبل از DBMS (نسل سوم):
-- 50 خط کد برای جستجو و فیلتر کردن!

با DBMS:
SELECT * FROM Teachers 
WHERE Department = 'Computer'
ORDER BY Salary DESC;

-- فقط 3 خط! 🎉

2. امنیت (Security) 

DBMS اجازه دسترسی رو کنترل می‌کنه:

GRANT SELECT ON Teachers TO Professor;
REVOKE DELETE ON Teachers FROM Student;

3. کنترل همزمانی (Concurrency Control) 

مثال: دو کاربر هم‌زمان می‌خوان حقوق استاد رو تغییر بدن

کاربر A: Salary = 5000 → 5500
کاربر B: Salary = 5000 → 5200

بدون DBMS: یکی از تغییرات از دست می‌ره! ❌
با DBMS: Lock می‌زنه و مدیریت می‌کنه ✅

4. بازیابی از خرابی (Recovery) 

مثال: وسط Update کردن حقوق، برق می‌ره!

بدون DBMS: داده‌ها خراب می‌شن ❌
با DBMS: Transaction رو Rollback می‌کنه ✅

🧠 نسل پنجم: KBMS (Knowledge Base Management System)

دوره زمانی: دهه 1990

تعریف: KBMS (Knowledge Base Management System): به جای داده، دانش را ذخیره می‌کند. دانش یعنی داده‌های پردازش شده.

مثال: سیستم تشخیص پزشکی

با DBMS: 

ذخیره می‌کنه:
- بیمار: علی
- تب: 39 درجه
- سرفه: دارد

با KBMS: 

دانش (قوانین):
- اگر (تب > 38) و (سرفه = دارد) → احتمال آنفلوانزا
- اگر (تب < 37.5) و (سردرد = دارد) → احتمال سرماخوردگی

KBMS خودش نتیجه‌گیری می‌کنه: "علی احتمالاً آنفلوانزا دارد"

کاربردها

  • سیستم‌های خبره (Expert Systems)
  • هوش مصنوعی (AI)
  • سیستم‌های تصمیم‌گیری

  • چه چالش‌هایی دارید؟
  • چه کارهایی باید خودتان انجام دهید؟
  • اگر به سال 1980 (DBMS) برسید، چه چیزهایی آسان می‌شود؟

تمرین 5 (تحلیلی):

چرا RDBMS (رابطه‌ای) محبوب‌ترین نوع DBMS شد؟ سه دلیل بیان کنید.

تمرین 6 (پیشرفته):

یک مثال از Data Mining در زندگی واقعی بزنید که:

  • از چه داده‌هایی استفاده می‌کند؟
  • چه الگویی کشف می‌کند؟
  • چه کاربردی دارد؟
