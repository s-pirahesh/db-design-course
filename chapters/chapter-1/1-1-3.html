بخش ۱.۱.۳: داده مانا و داده عملیاتی

🎯 مقدمه تعاملی

خوب دانشجوی عزیز، حالا که با سلسله مراتب ذخیره‌سازی آشنا شدیم، یه سوال مهم پیش میاد:

"وقتی برق می‌ره یا کامپیوتر خاموش می‌شه، داده‌های من چی می‌شن؟ 🤔"

این سوال ما رو به دو مفهوم بسیار مهم می‌رسونه:

  1. داده مانا (Persistent Data) - داده‌هایی که باقی می‌مونن
  2. داده عملیاتی (Operational Data) - داده‌هایی که روزانه باهاشون کار می‌کنیم

بیا با یک سناریو شروع کنیم:

فرض کن داری یک فرم ثبت‌نام دانشجو رو پر می‌کنی. نیمه‌ی راه یهو برق می‌ره! وقتی برق برمی‌گرده:

  • اگر اطلاعات فقط در RAM (حافظه موقت) بود → همه چیز از دست رفت ❌
  • اگر اطلاعات در دیسک (حافظه دائمی) ذخیره شده بود → همه چیز سالمه ✅

این تفاوت بین داده موقت و داده مانا است!

📖 تعریف دقیق داده مانا (Persistent Data)

تعریف : داده مانا: با قطع جریان برق یا بروز خرابی یا پایان برنامه از بین نمی‌رود. در واقع فایل ساختاری است برای ذخیره نمودن داده‌های مانا استفاده می‌شود.

ویژگی‌های داده مانا

  1. ماندگاری: بعد از قطع برق باقی می‌ماند
  2. استقلال از برنامه: بعد از بسته شدن برنامه همچنان وجود دارد
  3. دسترسی مجدد: می‌توان دوباره به آن دسترسی پیدا کرد
  4. عمر طولانی: تا زمانی که کاربر حذفش نکنه، باقی می‌مونه

📊 تعریف دقیق داده عملیاتی (Operational Data)

تعریف : داده‌های عملیاتی: داده‌هایی که به‌طور روزمره (در یک سازمان) استفاده می‌شوند.

چرا "عملیاتی"؟

داده عملیاتی یعنی داده‌ای که:

  1. روزانه باهاش کار می‌کنیم
  2. برای عملیات جاری سازمان لازمه
  3. به‌روز و فعال است
  4. تراکنش‌های روزمره روش انجام می‌شه

  2. اطلاعات دانشجو رو وارد می‌کنه → داده‌ها در RAM هستن (موقت)
  3. دکمه "ذخیره" رو می‌زنه → داده‌ها به دیسک منتقل می‌شن (مانا) ✅

📈 تفاوت داده موقت و مانا در عمل

سناریوی 1: برنامه نویسی بدون ذخیره مانا

# کد بدون ذخیره مانا (فقط RAM)
students = []  # لیست در حافظه RAM

def add_student(name, id):
    students.append({'name': name, 'id': id})
    print(f"دانشجو {name} اضافه شد")

# استفاده
add_student("علی", "123")
add_student("حسن", "456")

# اگر برنامه بسته شود → همه چیز از بین می‌رود! ❌

مشکل: با بستن برنامه، تمام اطلاعات از بین می‌رود!

سناریوی 2: برنامه نویسی با ذخیره مانا

import json

# کد با ذخیره مانا (دیسک)
def add_student(name, id):
    # 1. خواندن داده‌های قبلی از فایل (بازیابی)
    with open('students.json', 'r') as f:
        students = json.load(f)
    
    # 2. اضافه کردن دانشجوی جدید
    students.append({'name': name, 'id': id})
    
    # 3. ذخیره در فایل (ذخیره مانا)
    with open('students.json', 'w') as f:
        json.dump(students, f)
    
    print(f"دانشجو {name} به‌طور دائم ذخیره شد ✅")

# استفاده
add_student("علی", "123")
add_student("حسن", "456")

# حتی با بستن برنامه، اطلاعات در فایل students.json باقی می‌ماند ✅

✍️ تمرینات بخش ۱.۱.۳

تمرین 1 (تشریحی):

با یک مثال از زندگی واقعی (غیر از دانشگاه و بانک)، تفاوت بین داده مانا و داده موقت را توضیح دهید. چه اتفاقی می‌افتد اگر داده مانا نباشد؟

تمرین 2 (تستی):

کدام گزینه نادرست است؟

الف) داده مانا با قطع برق از بین می‌رود ب) داده عملیاتی به‌طور روزمره استفاده می‌شود ج) فایل یک ساختار برای ذخیره داده مانا است د) حافظه RAM برای ذخیره داده موقت استفاده می‌شود

تمرین 3 (سناریو):

یک کافی‌شاپ سیستم سفارش‌گیری دارد. هر روز 200 سفارش ثبت می‌شود.

سوالات:

  • کدام داده‌ها باید عملیاتی باشند؟
  • کدام داده‌ها باید مانا باشند؟
  • اگر سیستم تنها از RAM استفاده کند، چه مشکلاتی پیش می‌آید؟

تمرین 4 (تحلیلی):

در جدول زیر، مشخص کنید هر نوع حافظه برای چه نوع داده‌ای مناسب است:

نوع حافظهسرعتمانا؟مناسب برای
RAMبسیار سریعخیر؟
SSDسریعبله؟
HDDمتوسطبله؟
Cacheفوق‌العاده سریعخیر؟
#### تمرین 5 (محاسباتی):

یک پایگاه داده دانشگاه دارای اطلاعات زیر است:

  • 10,000 دانشجوی فعال (داده عملیاتی)
  • 50,000 دانشجوی فارغ‌التحصیل (داده آرشیو)
  • هر رکورد دانشجو: 500 بایت

محاسبه کنید:

  1. فضای لازم برای داده‌های عملیاتی
  2. فضای لازم برای داده‌های آرشیو
  3. اگر همه در SSD (گران) ذخیره شوند چقدر هزینه دارد؟ (فرض: SSD = 100 تومان/GB)
  4. آیا می‌توانیم برای بهینه‌سازی هزینه، داده‌های آرشیو را در HDD (ارزان) ذخیره کنیم؟

تمرین 6 (پیشرفته):

یک برنامه بازی آنلاین طراحی کنید که:

  • وضعیت فعلی بازی را در RAM نگه دارد (سریع)
  • هر 5 دقیقه وضعیت را در دیسک ذخیره کند (مانا)

سوالات:

  • چرا نمی‌توانیم همه چیز را فقط در RAM نگه داریم؟
  • چرا نمی‌توانیم همه چیز را مستقیماً در دیسک ذخیره کنیم؟
  • اگر بازی در دقیقه سوم crash کند، چه داده‌هایی از دست می‌رود؟
